# 📺 Smart Stream – Application de gestion et consultation de chaînes TV

## Présentation

**Smart Stream** est une application web responsive permettant de consulter, rechercher, filtrer et gérer des chaînes TV à travers une interface moderne et intuitive.

Le projet est développé avec HTML5, Tailwind CSS et JavaScript Vanilla ES6+, en utilisant MockAPI pour la gestion des données.

## 🎯 Objectifs

- Consulter dynamiquement une liste de chaînes TV.
- Rechercher des chaînes par nom ou numéro.
- Filtrer les chaînes par pays.
- Ajouter et supprimer des chaînes.
- Gérer les chaînes favorites.
- Conserver les préférences de l'utilisateur après rechargement.

## 🛠️ Technologies utilisées

- HTML5
- Tailwind CSS
- JavaScript Vanilla ES6+
- Fetch API
- MockAPI
- LocalStorage
- Git & GitHub
- Jira

## ✨ Fonctionnalités

- Affichage dynamique des chaînes TV depuis une API.
- Recherche instantanée par nom ou numéro.
- Filtrage des chaînes par pays.
- Ajout et suppression de chaînes.
- Ajout et retrait des favoris avec synchronisation API.
- Interface responsive avec une approche Mobile-First.
- Gestion des états de chargement et des erreurs.
- Sauvegarde du filtre sélectionné avec LocalStorage.

## 📚 Concepts étudiés

- Variables, constantes, tableaux et objets.
- Fonctions et fonctions fléchées.
- Modules ES6 : `import` et `export`.
- Méthodes `forEach()`, `map()`, `filter()`, `find()` et `push()`.
